# 證明與數學思維（Proofs & Mathematical Thinking）— 課程規畫

## 課程定位

這是一門**放在所有證明型課程之前**的基礎課。站上現有的群論、環論、體論、實分析等課，都默認學習者已經會讀一個「對所有……存在……」的句子、知道要證它第一步該寫什麼、能自己找反例、能判斷一段論證到底證明了什麼。`LEARNING_DESIGN.md` §10 指出的「課程地圖缺先備關係與推薦路徑」，最底層缺的就是這一門。

本課不教「證明技巧清單」，也不是邏輯學。它只回答一件事：

> 面對一句沒見過的數學陳述，我要怎麼知道它要求我做什麼、我手上有什麼可以用、卡住時下一步可以做什麼、以及做完之後我怎麼知道自己真的證完了。

整門課的 north star：

> 證明是一場說服「專門找碴的對手」的遊戲。陳述的邏輯形狀決定了你能走哪些步；定義是你手上唯一的武器；而一段論證之所以能涵蓋無限多種情況，是因為它對每一種情況做的事都一樣。

### 本課的特殊設計前提：沒有紙筆

本課的目標學習者在**電腦前學習，但大多數時間手邊沒有紙筆**。這不是附帶條件，而是整門課的設計前提：傳統證明課把大量認知工作交給草稿紙，本課必須在畫面上替代那些工作，而不是假裝它們不存在。

紙筆在學證明時其實同時做三件事，本課逐一給替代：

| 紙筆原本做的事 | 沒有紙筆會發生什麼 | 本課的替代 |
|---|---|---|
| 外部工作記憶：放已知、目標、中間結果 | 三步以上的推理在腦中崩掉 | **證明狀態板**：已知／目標雙欄，每一步自動更新；加上「已證明的引理變成一張新卡」的 chunking 機制 |
| 強迫精確：寫下來就必須說清楚誰是誰 | 模糊的想法在腦中「感覺像證明」 | **步法卡**：每一步都要從有限的合法動作裡選一張，變數身份（任意的／拿到的／你選的）在板上持續可見 |
| 驗收：寫完可以回頭檢查 | 沒有回饋，不知道自己對不對 | 結構由系統檢查；證人（witness）以鍵盤輸入公式、由系統對對手的出招實算；反例在**小世界**裡可完整列舉驗證 |

學習者有鍵盤可用，所以本課把「打字」當成合法的產出管道：輸入證人公式、輸入反例、輸入骨架的關鍵詞，以及 Ch24 的完整文字證明。這是本課對抗「只會認出正確答案、自己產不出來」的主要手段（見〈練習格式與產出優先護欄〉）。

### 與其他課的接口

本課是下列課程的建議先修，並在對應章節直接鋪接口：

- **群論 Foundations**：Ch10 的「唯一性＝假設有兩個」直接用 identity 唯一當遷移題；Ch19 等價關係＝切分，是 coset 與 quotient 的前置。
- **Rings & Ideals**：Ch2 的整除定義與 Ch19 的 well-definedness（換代表元答案不變）是 `ℤ/nℤ` 與 quotient ring 的前置；站上已有 representative-swap 類互動，本課應沿用同一視覺語法。
- **實分析**：Ch25 的 ε–N 是三層量詞遊戲的總考，交棒給實分析第一章。
- **點集拓撲／實分析**：Ch20 的可數與對角線論證。

### Ch1 實作時做出的設計決定（覆寫下文較早的寫法）

- **本課不走共用 `ChapterComponent`**：自有 lazy route 與外框（`proofs-chapter.component.ts`），不受全站章節殼、分頁籤與最大寬度容器限制，也不增加共用 chunk。
- **自有視覺語言「紙、墨、印」**：色票只在 `.pf-root` 內生效，並跟隨站上的深淺色切換。語意色：朱＝推翻／反例，靛＝證明／論證，琥珀＝你的預測，石墨＝例子。
- **證據狀態改用中文印章**，取代文中 `WITNESS`、`FINITE EXHAUSTION` 等大寫英文標籤：推翻＝方印（朱），證明＝圓印（靛），未定＝虛線框。形狀與文字都不同，不只靠顏色區分。
- **「證據盤」改為「你的信心 vs 邏輯狀態」雙儀表**（1.2）：例子確實會提高信心，這是合理的；但邏輯狀態一格都不會動。這比「例子沒有用」更誠實。
- **質數用點陣表現**：1681 個點排成 41 × 41 的正方形，讓「不是質數」可以直接被看見。
- **證明是主角**：本課不套用 `LEARNING_DESIGN.md`「證明預設放展開層」的規則，論證放在主流程；只把補充推導放進「想知道為什麼？」。
- **圓的區域數以精確幾何計算**（`ch1-chords.ts`）：用符號向量找出每一塊、用半平面裁切重建多邊形，並在每段弧與每個頂點周圍探測，確保細小區域也會被找到。已在 6,510 種擺法上與公式 `1 + 弦數 + Σ(k−1)` 逐一比對，全部吻合。
- **1.3 拆成「兩件事要對得上」**（試讀後修正）：初版只示範 L 形有 n + n + 1 格，再直接宣稱它「剛好是下一個奇數」，學習者卡在「為什麼剛好」。另外，具體圖寫 2n − 1、抽象圖寫 2n + 1，編號不一致。現在讓學習者分別回答「要補幾格」與「下一個奇數是多少」，再顯示兩者為何相等：L 形每圈多 2 格，奇數也每個多 2，而且兩者都從 1 開始。具體圖在每一圈的角落標出該圈格數，抽象圖則並列兩條等式。**通則：論證若依賴兩個量相等，兩邊都要各自算出來，不能只算一邊再宣稱另一邊相同。**

## 本課採用的 conventions

這些是課程慣例，不是所有教材的共同定義；UI 以 scope label 持續顯示，不只在第一次出現時說。

- **經典邏輯（classical logic）**：排中律與反證法都可用。直覺主義／建構式邏輯只在 Ch10 展開層提一次。
- **`ℕ = {0, 1, 2, …}`**。Hammack 等教材從 1 開始，Velleman 與 Lean 從 0 開始；凡畫面出現 `ℕ` 就顯示 `ℕ = {0,1,2,…}` 標籤。
- **整除（divides）**：`a ∣ b ⇔ 存在 k ∈ ℤ 使 b = ak`。因此 `0 ∣ 0` 為真、`3 ∣ 0` 為真、`0 ∣ 3` 為假。部分教材要求 `a ≠ 0`，在 Ch2 展開層說明。
- **偶數／奇數**定義在 `ℤ` 上：`n` 是偶數 ⇔ 存在 `k ∈ ℤ` 使 `n = 2k`；奇數 ⇔ 存在 `k ∈ ℤ` 使 `n = 2k+1`。
- **質數**：整數 `p ≥ 2`，其正因數只有 `1` 與 `p`。
- **「或」是包含性的（inclusive or）**；**「若 P 則 Q」是 material implication**（Ch3 解釋為何如此約定）。
- **函數**：`f: A → B` 必須對 `A` 的每個元素恰好給一個 `B` 中的值；domain 與 codomain 是宣告的一部分，不是公式的附屬品。
- **量詞的範圍永遠寫出來**：畫面上不出現沒有標明 domain 的 `∀x`。

## 全課共用元件（視覺語法）

以下元件跨章共用、語意固定。任何章節若要偏離，必須在該章 storyboard 中說明理由。

### A. 證明狀態板（Proof State Board）

- 左欄「已知（Givens）」，右欄「目標（Goal）」；目標可以是一個 stack（分情況、雙向證明時會分裂成多個子目標，並標出目前處理的是哪一個）。
- 每個被引入的物件都帶**身份標記**，用形狀＋文字（不只顏色）區分：
  - **任意的（arbitrary）**：虛線框，標「對手給的」——由「令 x 為任意……」引入，你不能對它做任何額外假設。
  - **拿到的（obtained）**：帶鉤框，標「從 H2 拿到」——由使用一個「存在」型已知引入，記錄來源。
  - **你選的（chosen）**：實線框，標「你選的」——你為「存在」型目標提出的證人，通常是一個依賴其他物件的公式。
- 每一步都留下 move log，可逐步回放；每一步標記為 **「形狀決定」** 或 **「需要想法」**。這個標記是本課的核心教學訊號：學習者會看見大部分步驟其實不需要靈感。
- **假暗示風險：** 板子會讓證明看起來像機械搜尋。對策：Ch6 起明示「需要想法」的步驟，Part III 整個在教那一步從哪裡來。

### B. 步法卡（Move Cards）

有限、逐章解鎖的合法動作，每張有固定圖示與一句中文：

| 對目標用 | 對已知用 |
|---|---|
| 證 `∀x∈A, P(x)` → 令 x 為 A 中任意元素 | 用 `∀x∈A, P(x)` → 代入一個特定元素 |
| 證 `P ⇒ Q` → 假設 P，改證 Q | 用 `P ⇒ Q` → 已有 P 時取得 Q |
| 證 `∃x, P(x)` → 提出證人 | 用 `∃x, P(x)` → 取出那個物件並命名 |
| 證 `P ∧ Q` → 拆成兩個目標 | 用 `P ∧ Q` → 拆成兩個已知 |
| 證 `P ∨ Q` → 假設 ¬P，改證 Q | 用 `P ∨ Q` → 分情況 |
| 證 `¬P` → 假設 P，改證矛盾 | 用兩個互相矛盾的已知 → 目標完成 |
| 證 `P ⇔ Q` → 兩個方向 | 展開定義（兩側都可） |
| 證 `A = B`（集合）→ 雙向包含（Ch17 解鎖） | 引用已證引理（Ch7 解鎖） |
| 逆否、反證（Ch8 解鎖）；歸納（Ch11 解鎖） | |

「引用已證引理」是 chunking 機制：一個證完的結果會變成一張具名卡（例如「平方是偶數 ⇒ 本身是偶數」），之後只佔一格工作記憶。

### C. 對手（Adversary）

- 量詞的 game semantics：目標裡的 `∀` 與已知裡的 `∃` 由對手出招；目標裡的 `∃` 由你出招；否定時角色互換。
- 對手**不是隨機抽樣**，而是依每題預先設計的最壞情況策略出招（例如先給 0、負數、極端值）。隨機對手會讓「贏了幾局」看起來像證明。
- 你回應對手的方式是**輸入一條規則**（例如 `y = x + 1`、`N = ⌊1/ε⌋ + 1`），不是輸入一個數字。贏一局標 `EXAMPLE`；寫出一條對任意出招都成立的規則並說出理由，才標 `GENERAL ARGUMENT`。

### D. 小世界（Tiny Worlds）

- 能被完整列舉的有限模型：至多 4 個元素的集合、`{1,2,3} → {a,b,c}` 的全部 27 個函數、小的 `ℤ/n`、小棋盤。
- 用途有二：在小世界裡**建造反例**（`WITNESS`）；以及在小世界內**完整檢查**（`FINITE EXHAUSTION`）。UI 必須區分「證明了這個小世界裡的事」與「證明了一般定理」。
- 小世界本身也是被教的技能：Ch13 會把 `LEARNING_DESIGN.md` 的 accidental-property audit 直接教給學習者——挑最小但不退化的例子。

### E. 骨架卡（Skeleton Cards）

- 每個重要證明壓縮成 3–4 拍，例如「√2 無理：假設是最簡分數 → 分子分母都是偶數 → 與最簡矛盾」。
- 間隔複習：骨架卡在下一章開頭、三章後、以及 Ch26 再出現；學習者先**輸入或排序**各拍，再翻牌比對。
- 存放在既有 `LearnProgressService` 的 step data（`saveStepData`），不新增儲存機制。

### F. 證據標籤（Evidence Labels）

沿用 `LEARNING_DESIGN.md`：`EXAMPLE`、`WITNESS`、`FINITE EXHAUSTION`、`SIMULATION`、`GENERAL ARGUMENT`。本課的特殊之處在於，**證據強度本身就是教學內容**（Ch1），之後每一個互動都要標。

### 共用元件實作約束

- 陳述以小型 AST 表示（量詞、連接詞、謂詞 `even / odd / divides / ∈ / = / <`、整係數多項式 term）；步法是 AST 上的純函數，便於單元測試。
- 證人輸入解析成整係數多項式，以展開＋合併同類項判定恆等；不引入 CAS 等大型依賴。
- 對手策略逐題手寫、決定性（deterministic），可重播。
- 狀態板、步法卡、對手輸入全部可以只用鍵盤完成：步法卡有數字快捷鍵，focus 可見，move log 有 `aria-live` 摘要（不逐 frame 播報）。

## 練習格式與產出優先護欄

只用選擇題與拖曳，學習者練到的常常是「認出答案」，不是「想出答案」。本課的通用規則：

1. **先承諾、再揭曉**：選項預設隱藏。學習者先輸入下一步的關鍵詞或證人公式，或至少按下「我想好了」，選項才出現，並和自己的想法比對。
2. **證人一律打字**：凡是 `∃` 目標，證人以公式輸入，由系統對對手的出招實算。
3. **反例一律建造**：在小世界裡指定物件，而不是從清單選一個。
4. **可用格式**：預測真假、下一步步法、Parsons problem（打亂的證明句子重排，含干擾句）、找出錯誤的那一行、把證明壓成骨架、打字寫完整證明（Ch24 起）。
5. **誠實的界線**：自由文字證明無法自動批改。Ch24 起的文字證明提供自評清單與範例證明比對，不假裝有 grader。

學習節奏建議（顯示在課程入口，不是章節）：每完成一個 Part，打字寫完一個完整證明；骨架卡複習在每章開頭自動出現。

## Part 0 · 為什麼需要證明

### Ch1 · 規律會騙人：證據有強度

**唯一核心 insight：** 例子能證明「存在」、能推翻「所有」；但對無限多種情況，再多成功的例子也證明不了「所有」——只有一段對每種情況都做同一件事的論證可以。

- 三個招牌情境：圓上點連線的區域數（1, 2, 4, 8, 16，第六個是 31）、`n² + n + 41` 撐了 40 步才失敗、奇數和的 L 形圖（一張對每個 n 都成立的圖）。
- 建立全課的證據標籤與「陳述狀態」：尚未決定／已推翻／已證明。
- **擁擠限制：** 不談邏輯符號、不談量詞、不教任何證明方法。只讓「證據有強度」成為可見事實。
- **詳細 storyboard 見文末。**

## Part I · 讀懂一句數學

### Ch2 · 定義是開關，也是工具

**唯一核心 insight：** 定義有兩個方向：要證「x 是偶數」，你必須造出一個 k；已知「x 是偶數」，你就拿到一個 k。

- 第一個衝突：0 是偶數嗎？−6 呢？`0 ∣ 0`、`3 ∣ 0`、`0 ∣ 3` 哪些成立？先下注再揭曉，答案依本課 convention 由定義推出，不是由印象。
- `a ∣ b` 是一句話（真或假），`a / b` 是一個數——並排對照這個常見混淆。
- 工具方向：在一個迷你狀態板上（Ch6 正式板的預覽），已知「x 是偶數」會讓板上出現一個帶鉤框的 `k`。
- 例子生成：為「奇數 + 奇數」挑例子時，`1 + 1` 是退化的（兩數相同），`3 + 5` 才能讓兩個 k 真正分開。
- **擁擠限制：** 只用偶奇、整除、有理數三個定義。不寫完整的證明文字（「令……、因此……」的句型留給 Ch6–7）；學習者只做「拿到」與「造出」這兩個動作。
- **符號對應：** `a ∣ b`、`∃k ∈ ℤ`；展開層：要求 `a ≠ 0` 的教材 convention。
- **詳細 storyboard 見文末。**

### Ch3 · 「若…則」是一個承諾

**唯一核心 insight：** `P ⇒ Q` 只在「P 成立而 Q 失敗」時被打破；其餘三種情況都沒有違約。

- 3.1 且、或、非：在四格圖裡圈出成立的格（包含性的「或」）。
- 3.2 只有一格算違約：「考 100 分就請你吃冰」的四種情況；再用「若 n 是 4 的倍數，則 n 是偶數」說明數學為什麼把「沒觸發」算成真。
- 3.3 Wason 選卡任務：A、K、4、7，規則「若一面是母音，另一面是偶數」，要翻哪幾張？（A 與 7。）先預測再揭曉，再用同構的生活版本對照，讓「結構相同」可見。
- 3.4 空洞為真（vacuous truth）：前提不可能成立時，承諾自動守住。
- 3.5 逆命題（converse）與逆否命題（contrapositive）：在同一張四格圖上看違約格的位置——逆否在同一格、逆命題在另一格。
- 3.6 `P ⇔ Q` 是兩個承諾：兩格違約，只剩對角線。
- 實作時拆成六幕（原規畫五幕）：「只有一格算違約」是本章核心，需要自己的一幕。詳細 storyboard 見文末。
- **evidence：** 真值表是四格的 `FINITE EXHAUSTION`，而且**真的證明了**邏輯等價——因為這個世界本來就只有四格。這是第一個「完整列舉＝合法證明」的例子，並明示它和 Ch1 的無限情況有何不同。
- **擁擠限制：** 不引入量詞；不做數學證明。

### Ch4 · 量詞是一場對手遊戲

**唯一核心 insight：** 「對所有 x」由對手出招，「存在 y」由你出招；量詞的順序就是出招順序，換了順序就換了遊戲。

- 第一個衝突：`∀x∈ℤ ∃y∈ℤ, y > x` 與 `∃y∈ℤ ∀x∈ℤ, y > x` 都成立嗎？
- 主要互動：對手出 x，你**輸入規則** `y = x + 1`；第二句你必須先出 y，對手立刻出 `x = y` 贏下。
- 換 domain、固定陳述：`∀x ∃y, y < x` 在 `ℤ` 成立、在 `ℕ` 不成立（對手出 0）。
- 找出日常數學句子裡藏起來的量詞：「偶數加偶數是偶數」藏了兩個 `∀`；「`x² = 2` 有解」藏了 `∃` 與 domain。
- **non-degenerate：** 避開 `∀∀` 這種順序無關的例子；主例必須讓順序改變真假。
- **擁擠限制：** 不談否定（Ch5）；不談 ε。
- 實作拆成五幕：對手先出、你先出、換一個世界、藏起來的量詞、換你當對手。詳細 storyboard 見文末。

### Ch5 · 否定就是交換角色

**唯一核心 insight：** 否定一句量詞陳述，就是讓你和對手交換位置：`∀` 變 `∃`、`∃` 變 `∀`，最裡面的條件被否定。

- 第一個衝突：否定「每個學生都有一門課不及格」。常見錯誤「每個學生都沒有不及格」vs 正解「有學生每門課都及格」。
- 否定機器：一步一步把 `¬` 推過量詞，每一步在對手遊戲板上顯示角色互換。
- 否定「若…則」：`¬(P ⇒ Q) ≡ P ∧ ¬Q`，回接 Ch3 的破約格。
- 反例就是否定陳述的證明：回收 Ch1 的 `WITNESS`。
- **遷移：** 否定「f 是遞增函數」，為 Ch25 預留三層量詞的伏筆。

## Part II · 證明的步法

### Ch6 · 目標的形狀決定第一步

**唯一核心 insight：** 在想到任何點子之前，目標的邏輯形狀就已決定證明的開頭與結尾；你真正需要想的只有中間。

- 正式引入證明狀態板。主例：「若 a、b 是偶數，則 a + b 是偶數」——走完之後，move log 顯示大多數步驟標「形狀決定」，只有「取 `m = k + l`」標「需要想法」。
- Ch2 章末已有五步預告卡（「照定義」／「要想」）。Ch6 的標籤要能對回那張卡：「照定義」對應「形狀決定」，「要想」對應「需要想法」。
- 6.1 狀態板：已知在左、目標在右。
- 6.2 目標的形狀 → 第一張卡。
- 6.3 已知的形狀 → 能拿到什麼。
- 6.4 三種變數身份：任意的、拿到的、你選的。招牌 bug：兩個偶數都寫成 `2k`，等於偷偷只證明了 `a = b` 的情況。用 `a = 4, b = 6` 讓兩個 k 數值分開，矛盾立刻可見。
- 6.5 正推與倒推（forward–backward）：目標往回展開、已知往前展開，在中間會合。
- **擁擠限制：** 只做直接證明，不碰逆否、反證、歸納。

### Ch7 · 證明的中段：從定義走到定義

**唯一核心 insight：** 中段通常是一座橋——把已知與目標都展開成定義，再找一個證人公式或一串代數把兩端接起來。

- 7.1 兩端都展開：`a ∣ b ∧ b ∣ c ⇒ a ∣ c`，用 `a = 3, b = 12, c = 60`（k = 4、l = 5 不相等）作 non-degenerate 示範。
- 7.2 證人是一個公式：輸入 `k·l`，系統以多項式恆等驗證。
- 7.3 橋搭不起來時，命題也許是錯的：`a ∣ (b + c) ⇒ a ∣ b`？以 `3 ∣ (1 + 2)` 推翻。
- 7.4 一個定理變成一張新卡：證完的結果加入步法卡，示範 chunking 如何減輕工作記憶負擔。
- **符號對應：** 多項式恆等、證人依賴於拿到的物件。

### Ch8 · 逆否與反證（contrapositive / proof by contradiction）：當目標是否定句

**唯一核心 insight：** 目標是「不是……」或「沒有……」時很難直接抓；逆否與反證把否定的目標換成一個可以使用的已知。

- 8.1 逆否：`n²` 是偶數 ⇒ `n` 是偶數。直接證很難；逆否「n 是奇數 ⇒ n² 是奇數」可以用 Ch7 的工具直接走。
- 8.2 反證：板上目標變成「找出一對互相矛盾的已知」。
- 8.3 √2 是無理數：串起 8.1 證好的引理卡。
- 8.4 質數有無限多個，以及「`p₁…pₙ + 1` 一定是質數」的迷思：`2·3·5·7·11·13 + 1 = 30031 = 59 · 509` 是 decisive `WITNESS`；正確的說法是它有一個不在清單裡的質因數。
- 8.5 何時選哪一種：逆否是「矛盾恰好是 ¬P」的反證；能用逆否時證明通常更乾淨。

### Ch9 · 分情況與 WLOG

**唯一核心 insight：** 分情況的力量來自「情況蓋滿了所有可能」；不失一般性（WLOG）只在情況之間真的對稱時才合法。

- 9.1 情況必須蓋滿：把 domain 畫成被切開的區域，漏掉的情況（例如只分 `x > 0` 與 `x < 0`，漏掉 `x = 0`）顯示為未覆蓋的空隙。
- 9.2 已知是「或」：分頭處理。主例：`n² + n` 是偶數（分奇偶），再對照一行的 `n(n+1)` 證法。
- 9.3 目標是「或」：假設其中一個不成立，改證另一個。
- 9.4 WLOG：對稱陳述可以假設 `a ≤ b`；對不對稱陳述使用 WLOG 的錯誤示範。

### Ch10 · 存在、構造與唯一

**唯一核心 insight：** 證存在最好的方式是把它造出來；證唯一的標準動作是「假設有兩個，證明它們相等」。

- 10.1 造出來：任兩個有理數之間有有理數（證人是平均數，一個配方）。
- 10.2 不造出來也能證明存在：存在無理數 a、b 使 `aᵇ` 是有理數（`√2^√2` 分兩種情況）。標 `GENERAL ARGUMENT · NON-CONSTRUCTIVE`。展開層：建構式邏輯為何不接受這個證明。
- 10.3 唯一：假設 `e`、`e'` 都是單位元，則 `e = ee' = e'`——群論課的遷移題。
- 10.4 「存在且唯一」是兩份工作：板上分裂成兩個子目標。常見錯誤：用「我找到的那個確實可以」來證唯一，其實又證了一次存在。

### Ch11 · 數學歸納法（mathematical induction）：用有限論證證無限

**唯一核心 insight：** 歸納有效，是因為「從 n 推到 n+1」那段論證對每個 n 都一模一樣，所以一段有限的論證可以被重複使用無限次。

- 11.1 同一塊步驟疊出每一個 P(n)：互動把 P(7) 的完整證明展開成「base + 七塊相同的 step」，看見 step 的一致性才是重點。
- 11.2 回到 Ch1：奇數和的 L 形，就是歸納步。Ch1 留下的 proof debt 在此只補精度，不改結論。
- 11.3 L 形三格骨牌鋪滿缺一格的 `2ⁿ × 2ⁿ` 棋盤（缺任意一格都可以）。
- 11.4 「所有馬同色」：互動找出 step 在 `n = 1 → 2` 那一格失效（兩群馬沒有重疊）。
- 11.5 強歸納：每個 `≥ 2` 的整數都是質數的乘積——可以用所有更小的情況。
- **擁擠限制：** 遞迴定義、結構歸納放展開層。

### Ch12 · 最小反例（minimal counterexample）

**唯一核心 insight：** 如果陳述有反例，就有最小的反例；證明「最小反例會生出更小的反例」，就等於證明根本沒有反例。

- 12.1 最小反例的自我毀滅：每個 `≥ 2` 的整數都有質因數。
- 12.2 世界換了，方法就失效：`ℕ` 的每個非空子集都有最小元（well-ordering），`ℚ⁺` 的非空子集卻不一定有——`ℚ⁺` 本身就沒有最小元。Non-degenerate transfer：固定論證、只換世界。
- 12.3 歸納與最小反例是同一件事的兩面：同一個命題用兩種方式各證一次，並排比對骨架。

## Part III · 找到想法

本 Part 主要汲取 Pólya《How to Solve It》與 Mason–Burton–Stacey《Thinking Mathematically》。所有例題都刻意選擇**能在腦中完成**的規模。

### Ch13 · 先特化，再推廣（specializing / generalizing）

**唯一核心 insight：** 卡住時先在小到能放進腦中的例子裡做事；但要挑不退化的例子，並讓它長出猜想，而不是把例子的巧合當成規律。

- 13.1 挑一個放得進腦中的例子。
- 13.2 退化的例子會騙你：「若 `a ∣ bc`，則 `a ∣ b` 或 `a ∣ c`」——只用質數 a 測試會一直通過；`4 ∣ 2·2` 推翻它。這一節把 `LEARNING_DESIGN.md` 的 accidental-property audit 直接教給學習者。
- 13.3 從表格長出猜想：哪些正整數能寫成至少兩個連續正整數之和？小例子會長出「2 的冪做不到」的猜想。
- 13.4 推廣：把數字換成字母，看論證用到了例子的哪個特殊性質。為猜想的一個方向（有奇因數 ⇒ 可以）給出 `GENERAL ARGUMENT`，另一個方向放展開層。

### Ch14 · 不變量（invariant）

**唯一核心 insight：** 若某個量在每個允許的操作下都不變，那麼起點和終點的這個量不同時，終點就永遠到不了。

- 14.1 挖掉對角兩格的西洋棋盤，不能用骨牌鋪滿：每張骨牌蓋一黑一白。
- 14.2 黑板遊戲：寫著 1 到 10，每次擦掉兩數 a、b，寫上 `|a − b|`；總和的奇偶性不變，所以最後剩下的數是奇數。
- 14.3 不變量只能說「不可能」：顏色數平衡不保證能鋪滿（兩個不相鄰、顏色相反的孤立格子就是 `WITNESS`）。必要條件 ≠ 充分條件。
- 14.4 單變量（monovariant）：嚴格遞減的自然數量保證過程會停——回接 Ch12。
- **evidence：** 隨機模擬一千局都沒到達目標，標 `SIMULATION`，並明示它不能取代不變量論證。

### Ch15 · 鴿籠原理與極端原理（pigeonhole / extremal principle）

**唯一核心 insight：** 鴿籠：數量超過容器就必有碰撞，即使你指不出是哪一對；極端：去看最大、最小、最遠的那一個，常常能直接逼出結論。

- 15.1 鴿籠：從 1 到 2n 任選 n + 1 個數，必有兩數相鄰。這是不建構式的存在（回接 Ch10）。
- 15.2 設計籠子：同一題改成「必有一數整除另一數」，籠子換成「奇數部分相同」——選對分類就是全部的想法。
- 15.3 極端原理：無限方格上每格是一個自然數，且等於四鄰居的平均 ⇒ 全部相等（看最小的那一格）。遷移：允許負整數時 `f(x, y) = x` 是反例，因為 `ℤ` 沒有最小元——回接 Ch12。

### Ch16 · 倒推與輔助問題

**唯一核心 insight：** 不知道怎麼開始時，從目標往回問「什麼能直接推出它？」，或先解一個更簡單、更特殊、或更一般的相關問題。

- 16.1 從終點往回走：用 3 公升與 5 公升的水壺量出 4 公升。
- 16.2 換一個更簡單的問題：同一題推廣到「a 公升與 b 公升能量出哪些量」，留下 gcd 的伏筆。
- 16.3 你見過相關的題目嗎？從已累積的骨架卡中挑出可用的一張（回收 E 元件）。
- 16.4 卡住也是資料：Mason 式「卡住日誌」——輸入「我知道什麼／我想要什麼／我卡在哪」，作為沒有紙筆時的外部記憶。

## Part IV · 遷移到新材料

高等數學的通用材料：集合、函數、關係、基數。本 Part 同時是 Part I–II 的遷移測試：同一套步法，用在新的物件上。

### Ch17 · 集合：追元素

**唯一核心 insight：** 證兩個集合相等，不是看圖覺得一樣，而是追著一個任意元素，雙向證包含。

- 17.1 `A ⊆ B` 就是 `∀x (x ∈ A ⇒ x ∈ B)`——直接搬上 Ch6 的板子。`∅ ⊆ A` 是空洞為真（回接 Ch3）。
- 17.2 集合相等＝雙向追元素：分配律 `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`。
- 17.3 文氏圖什麼時候會騙你：四個圓畫不出全部 16 個區域；圖是 `EXAMPLE` 級的直覺，不是證明。
- 17.4 小世界反例：`A ∖ (B ∖ C) = (A ∖ B) ∖ C`？以 `A = B = C = {1}` 推翻。

### Ch18 · 函數：箭頭圖的形狀

**唯一核心 insight：** 單射（injective）是「不會撞在一起」，滿射（surjective）是「每個目標都被打到」；兩者都依賴你宣告的 domain 與 codomain，不是公式本身的性質。

- 18.1 函數是箭頭圖：`{1,2,3} → {a,b,c}` 的 27 個函數完整列舉，其中 6 個是雙射（`FINITE EXHAUSTION`）。
- 18.2 證單射＝「撞在一起的其實是同一個」，回接 Ch10 的唯一性動作。
- 18.3 證滿射＝對每個目標造出來源，回接證人公式。
- 18.4 同一個公式、四種宣告：`x²` 在 `ℝ→ℝ`、`[0,∞)→ℝ`、`ℝ→[0,∞)`、`[0,∞)→[0,∞)` 的單射／滿射狀態各不相同。固定公式、只換宣告的受控遷移。
- 18.5 合成與反函數：`g∘f` 單射 ⇒ `f` 單射，但 g 不一定；以 `{1} → {a,b} → {x}` 的小世界反例說明。

### Ch19 · 等價關係（equivalence relation）就是切分（partition）

**唯一核心 insight：** 一個「像相等」的關係（自反、對稱、遞移）恰好等於把集合切成互不重疊的塊；選代表元只是替每一塊取名字。

- 19.1 三條規則：同奇偶、同餘 mod n、同月出生。
- 19.2 等價關係 ⇔ 切分：雙向對應，各自一個 `GENERAL ARGUMENT`。
- 19.3 不遞移的「差不多」切不出塊：「相差小於 1」是 non-degenerate 對照。
- 19.4 換代表元，答案不變嗎？`[a] + [b] := [a + b]` 在 mod 5 下是 well-defined；`[a] ↦ [2ᵃ]` 不是：`[0] = [5]`，但 `2⁰ = 1`、`2⁵ = 32 ≡ 2`。沿用站上 representative-swap 的視覺語法。

### Ch20 · 無限也有大小

**唯一核心 insight：** 比較兩個集合的大小靠的是配對，不是數數；而 Cantor 對角線論證證明了任何「列出所有無限二元序列」的清單都必然漏掉一個。

- 20.1 配對而不是數數。
- 20.2 部分可以和整體一樣大：`ℕ` 與偶數、`ℕ` 與 `ℤ`（之字形配對）。
- 20.3 `ℕ × ℕ` 也能排成一列，因此 `ℚ` 可數（countable）。
- 20.4 對角線論證：學習者給一份清單（或讓對手給），系統建構出不在清單上的序列——`∀ 清單 ∃ 漏掉的序列`，回接 Ch4 的對手遊戲。以二元序列為主例，避開 `0.999… = 1` 的雙重表示問題；實數版本放展開層。
- **展開層：** Cantor 定理 `|A| < |P(A)|`。

## Part V · 自己當自己的老師

自學證明最大的困難是沒有人批改。本 Part 把批改者的工作拆成可練習的檢查動作。

### Ch21 · 錯誤證明圖鑑

**唯一核心 insight：** 大多數錯誤證明落在少數幾種模式：偷用結論、證了反方向、除以可能為零的數、只驗了例子、變數身份混淆、情況沒有蓋滿。

- 21.1 「1 = 2」：藏起來的除以零。
- 21.2 循環論證：結論偷偷出現在已知裡。
- 21.3 證了反方向：把 `Q ⇒ P` 當成 `P ⇒ Q`（回接 Ch3）。
- 21.4 綜合找錯：每題先指出錯在哪一行，再判斷錯誤類型。圖鑑每一種錯誤都連回它第一次出現的章節。

### Ch22 · 每個假設都在工作

**唯一核心 insight：** 好定理的每個假設都有工作；拿掉其中一個，就應該找得到反例。找不到時，要嘛定理可以更強，要嘛你還沒看懂它。

- 22.1 拿掉一個假設：「p 是質數且 `p ∣ ab` ⇒ `p ∣ a` 或 `p ∣ b`」拿掉「質數」→ `4 ∣ 2·2`（回收 Ch13）。
- 22.2 證明沒用到某個假設時：展示一段「證明」，它若是對的就會證出一個錯的更強陳述——說明「沒用到假設」是警訊。
- 22.3 Lakatos：反例逼定義長大。Euler 公式 `V − E + F = 2` 遇上相框狀多面體（得 0），定義被迫修正。這裡使用 3D 是合理的：多面體的洞需要旋轉才看得出來。依 `LEARNING_DESIGN.md` §5 提供初始視角、一鍵回正、受限相機與 reduced-motion 替代。

### Ch23 · 讀一個證明：壓縮成骨架

**唯一核心 insight：** 讀懂一個證明的標準，不是每一行都點頭，而是能把它壓成三到四拍的骨架，並在蓋起來之後重建。

- 23.1 讀之前先猜骨架：只看陳述的形狀（Ch6），預測開頭與結尾。
- 23.2 為每一行標上步法卡。
- 23.3 壓縮成三拍。
- 23.4 蓋起來重建：輸入各拍關鍵詞，再翻牌比對。
- 這一章是學習者離線讀教科書時的標準流程；章末把它整理成可帶走的閱讀卡。

### Ch24 · 從狀態板到文字證明

**唯一核心 insight：** 狀態板是找到證明的方式；寫給人看的證明，必須用文字說清楚每個變數是任意的、拿到的、還是你選的，以及每一步為什麼成立。

- 24.1 每張步法卡對應一句標準句型：「設 x 為任意整數」「因為 a 是偶數，存在 k ∈ ℤ 使 a = 2k」「取 m = k + l」。
- 24.2 讀者需要的三件事：誰是任意的、東西從哪裡拿到、為什麼成立。
- 24.3 打字寫一個完整證明，再依自評清單逐項檢查（每個物件都引入了嗎？每個假設都用到了嗎？情況蓋滿了嗎？），最後和範例證明並排比對。誠實標明：系統不批改自由文字。

## Part VI · 收束

### Ch25 · ε–N：三層量詞的總考

**唯一核心 insight：** 數列極限的定義，就是三層量詞的對手遊戲——對手給 ε，你回 N，對手再挑任何 `n ≥ N`；證明極限，就是寫出一條 N 關於 ε 的回應規則。

- 25.1 三層出招順序：`∀ε > 0 ∃N ∀n ≥ N, |aₙ − L| < ε`。
- 25.2 N 是 ε 的函數：對 `1/n → 0` 輸入 `N = ⌊1/ε⌋ + 1`，對手用越來越小的 ε 測試。
- 25.3 證明不收斂：`(−1)ⁿ` 不收斂；否定後角色互換，換你出 ε（回接 Ch5）。
- 交棒給實分析課。展開層：uniform 與 pointwise 只差量詞順序。

### Ch26 · 綜合診斷

- 混合題，不提示該用哪種方法。每題的流程：判斷陳述形狀 → 選第一張卡 → 標證據類型 → 找錯或建反例 → 重建骨架。
- 診斷結果對應回各章，指出最需要回去複習的一章。

最終收束圖：

```text
面對一句沒見過的陳述：
  它要求我做什麼？ ────► 拆出量詞與連接詞的形狀（Ch3–5）
  第一步與最後一步？ ──► 目標與已知的形狀決定（Ch6）
  中間怎麼接？ ────────► 展開定義、證人公式、已證引理（Ch7）
  直接走不通？ ────────► 逆否、反證、分情況、歸納、最小反例（Ch8–12）
  完全沒想法？ ────────► 特化、不變量、鴿籠、極端、倒推（Ch13–16）
  它也許是錯的？ ──────► 在小世界裡建反例（Ch1、Ch13、Ch17–18）
  我真的證完了嗎？ ────► 錯誤圖鑑、假設檢查、骨架重建（Ch21–23）
```

最終圖卡：

> 證明是一場說服「專門找碴的對手」的遊戲。形狀告訴你怎麼開始，定義給你武器，例子幫你找路——但只有對每一種情況都做同一件事的論證，才算贏。

## Ch1 詳細 storyboard · 規律會騙人：證據有強度

### 全章設計句

```text
核心 insight：
例子能證明「存在」、能推翻「所有」；但對無限多種情況，再多成功的例子也證明不了「所有」。
只有一段對每一種情況都做同一件事的論證可以。

學習者原本可能怎麼誤解：
1. 試了很多次都對，就是對的；或「越多例子越接近證明」。
2. 一個反例只是例外，規律「大致上」還是成立。
3. 證明只是把顯然的事寫得很囉嗦。
4. 反向誤解：圖只是例子，不可能是證明。

第一個具體問題：
圓上放 n 個點、兩兩連線（任三條弦不共點），最多把圓分成幾塊？
n = 1, 2, 3, 4, 5 依序是 1, 2, 4, 8, 16。n = 6 是多少？

一般機制如何表述：
一個「所有 x 都滿足 P」的陳述，若 x 的範圍是無限的，就只能被一般論證證明、被一個反例推翻；
有限範圍則可以被完整檢查證明。一個「存在 x 滿足 P」的陳述，一個例子就能證明。

主例子的 accidental properties：
- 圓的區域數與點的位置有關：正六邊形頂點會讓三條弦共點，只得 30 塊。
  → 預設採一般位置，scope label 持續顯示；正多邊形的情況放展開層。
- n² + n + 41 在 n = 40、41 失敗，兩者都和 41 有關，學習者可能以為「只在 41 的倍數附近失敗」。
  → 同時展示 n = 44：2021 = 43 · 47。
- 奇數和的 L 形圖畫的是某一個特定的 n，學習者可能以為它只是又一個例子。
  → 讓 n 可以連續增加，並明示每一步加的 L 形都是同一種構造。

哪個 non-degenerate state 讓角色真正分開：
n² + n + 41 的「39 個成功、第 40 個失敗」：「例子很多」與「陳述為假」同時成立。
這讓「例子數量」與「陳述狀態」在畫面上明顯分離。

主要視覺模型：
「陳述卡＋證據盤」。每個陳述是一張卡，狀態只有三種：尚未決定／已推翻／已證明。

只有 WITNESS 能翻成「已推翻」，只有 GENERAL ARGUMENT（或有限範圍的 FINITE EXHAUSTION）能翻成「已證明」。

視覺可能造成的假暗示：
證據幣越堆越高，看起來像進度條。對策：證據盤不是容量條，沒有填滿刻度、沒有百分比；
堆疊旁持續顯示「例子數：39　狀態：尚未決定」。

學習者能操作的變數：
圓上的點數與位置；n 的值；奇數和圖的 n；證據幣的類型（1.4）。

操作時保持不變的東西：
陳述的狀態只由「證據類型」決定，不由證據數量決定。

預測 → 回饋 → 壓縮：
每節開始先下注（第 6 個是幾？第 40 個是質數嗎？），揭曉後把證據幣投進盤，最後壓成圖卡。

evidence 類型：
1.1 WITNESS（n = 6 的實際區域數）；1.2 FINITE EXHAUSTION（只證明 0–39）＋ WITNESS（n = 40）；
1.3 GENERAL ARGUMENT（L 形構造）；1.4 綜合分類。

本節採用 exact general statement 還是有 scope 的低解析度版本：
1.1 與 1.2 是 exact。1.3 的 L 形是一個真正的一般論證，但「為什麼一張對每個 n 都一樣的圖能涵蓋無限多種情況」
要到 Ch11 才正式化為歸納法；之後只會補精度，不改結論。

省略了哪一筆 proof debt：
L 形論證的正式歸納形式（Ch11.2 償還）；Moser 公式為何是 C(n,4) + C(n,2) + 1（展開層，本課不證）。

特例 detector 與 course convention 如何持續標示 scope：
圓的情境持續顯示 `GENERAL POSITION · 任三弦不共點`；1.2 顯示 `n ∈ ℕ = {0,1,2,…}`。

正式內容放在哪個展開層：
Moser 公式與區域數 1, 2, 4, 8, 16, 31, 57；正多邊形共點時的 30；
n² + n + 41 = n(n+1) + 41 在 n = 40 變成 41²；奇數和的代數版本 (n+1)² − n² = 2n + 1。

最後如何檢查能否遷移：
固定「證據類型 → 能支持的結論強度」，換一個表面：
「4 到 100 的每個偶數都能寫成兩個質數之和」可以用 FINITE EXHAUSTION 證明；
「所有大於 2 的偶數都能寫成兩個質數之和」（Goldbach 猜想）至今既未被證明、也未被推翻。
同樣的證據，在有限範圍是證明，在無限範圍只是支持。
```

### 1.1 · 規律在第六步背叛

- **衝突／預測：** 依序顯示 n = 1 到 5 的圓與區域數 1, 2, 4, 8, 16。請學習者先輸入 n = 6 的預測（多數人會輸入 32）。
- **可操作模型：** 圓上可拖曳的點。區域即時標號計數，學習者也能自己點擊區域確認。預設位置為一般位置；拖到三弦共點時顯示提示，並把這個情況導向展開層，不讓它搶走主線。
- **揭曉：** n = 6 是 31。證據幣 `WITNESS` 投入，陳述卡「區域數每次加倍」翻成「已推翻」。
- **引導注意：** 只高亮「預測 32 vs 實際 31」這一對數字，不同時展示公式。
- **壓縮圖卡：** 「前五個都對，不代表第六個也對；一個反例就足以推翻『所有』。」
- **擁擠限制：** 不給 Moser 公式（展開層）。不談為什麼是 31。

### 1.2 · 撐了四十步的規律

- **衝突／預測：** 陳述「對所有 `n ∈ ℕ`，`n² + n + 41` 是質數」。計數器從 0 開始自動逐一檢查，每一格顯示值與「質數 ✓」。跑到 39 時暫停，問：n = 40 呢？還要再試多少個才夠？
- **可操作模型：** 學習者可以自己按「下一個」，也可以讓計數器連續跑。證據盤堆出 40 枚 `EXAMPLE`（其實是 0–39 的 `FINITE EXHAUSTION`），陳述卡維持「尚未決定」。
- **揭曉：** `40² + 40 + 41 = 1681 = 41²`。`WITNESS` 投入，陳述翻成「已推翻」。再展示 n = 41（`41 · 43`）與 n = 44（`2021 = 43 · 47`），擋掉「只在 41 附近失敗」的錯誤泛化。
- **可選的「為什麼」：** `n² + n + 41 = n(n+1) + 41`，n = 40 時變成 `40·41 + 41 = 41·41`。放在展開層。
- **壓縮圖卡：** 「四十個成功，只證明了那四十個。」
- **擁擠限制：** 不談質數分布、不談其他多項式。

### 1.3 · 一張對每個 n 都成立的圖

- **衝突／預測：** `1 = 1`、`1 + 3 = 4`、`1 + 3 + 5 = 9`……前 n 個奇數的和看起來是 n²。在 1.1 與 1.2 之後，學習者應該先懷疑：這會不會也在某一步背叛？
- **可操作模型：** 一個 n × n 的方格正方形。按「下一步」時，沿右邊與上邊加上一條 L 形，L 形的格數是 `2n + 1`，正方形變成 (n+1) × (n+1)。n 可以一直加。
- **引導注意：** 每次加上的 L 形用同一種線型與標註「n + n + 1」。動畫只強調「這一步做的事與 n 無關」。
- **關鍵對比：** 1.1 的圓每多一個點，新增區域數沒有一個固定的構造可以預測；這裡每一步都是同一個構造。這就是例子與論證的差別。
- **evidence：** `GENERAL ARGUMENT`，陳述翻成「已證明」。畫面註明：正式寫法（歸納法）在 Ch11，屆時只補精度。
- **壓縮圖卡：** 「論證之所以能涵蓋無限多種情況，是因為它對每一種情況做的事都一樣。」
- **擁擠限制：** 不出現歸納法的名稱或符號。

### 1.4 · 例子的兩種力量

- **衝突／預測：** 一疊陳述卡，每張附一種證據。學習者要判斷每張的狀態：已證明、已推翻，還是尚未決定。
  - 「存在一個大於 100 的質數」＋一個例子 101 → 已證明（存在型，一例足矣）。
  - 「所有質數都是奇數」＋例子 2 → 已推翻。
  - 「所有大於 2 的偶數都是兩質數之和」＋一百萬個成功例子 → 尚未決定。
  - 「1 到 100 的每個整數都是四個平方數之和」＋程式逐一檢查完 → 已證明（有限範圍）。
- **可操作模型：** 拖曳證據幣到陳述卡上，卡片即時顯示狀態與理由；錯誤的判斷給出針對該迷思的提示（例如「例子很多」→「數量不改變狀態」）。
- **壓縮圖卡（全章收束）：**「例子能證明『存在』、能推翻『所有』；要證明無限範圍的『所有』，只能靠論證。」
- **擁擠限制：** 不引入 `∀`、`∃` 符號（Ch4）；只用中文「所有」「存在」。

### transfer（全章一次受控遷移）

固定「證據類型 → 能支持的結論強度」，只換範圍：

- 「4 到 100 的每個偶數都是兩個質數之和」：完整列舉即證明（`FINITE EXHAUSTION`）。
- 「所有大於 2 的偶數都是兩個質數之和」：同樣的檢查只能支持，不能證明；這是 Goldbach 猜想，至今未被證明或推翻。

同一種證據，在有限範圍是證明，在無限範圍只是支持——證明力取決於陳述的範圍，而不是檢查得多努力。

### Ch1 畫面與實作約束

- 陳述卡與證據盤是全課共用元件的第一個版本（F 元件）；之後各章都用同一套證據幣圖示。
- 證據盤不得畫成進度條或容量條；狀態只由證據類型決定。
- 圓的區域計數以實際幾何計算：區域數 ＝ 1 ＋ 弦數 ＋ Σ（過每個內部交點的弦數 − 1），或以離屏 canvas flood fill 標號；不可直接套 Moser 公式顯示，否則學習者拖到非一般位置時，數字會和畫面不符。
- 所有預測輸入可用鍵盤完成；揭曉前選項不出現（產出優先護欄）。
- 動畫（L 形加入、計數器）可暫停、重播、步進；reduced motion 下改為即時切換狀態，不遺失資訊。
- 非色彩辨識：證據幣以形狀＋文字標籤區分，陳述狀態以圖示＋文字顯示，不只靠紅綠。

### Ch1 完成驗收

學習者離開本章後應能：

1. 說出為什麼 39 個成功例子不能證明「對所有 n 成立」，而 1 個反例就能推翻它。
2. 判斷一個陳述是「存在」型還是「所有」型，並說出各自需要什麼證據。
3. 區分有限範圍（完整檢查即證明）與無限範圍（需要論證）。
4. 解釋 L 形圖為什麼是論證而不只是例子：每一步做的事都相同。
5. 在新的陳述上正確選擇證據類型，而不是看證據數量。

若學習者只能背出「例子不是證明」，卻不能在 1.4 的分類中正確處理「存在」型陳述與有限範圍，本章就還不算完成。

## Ch2 詳細 storyboard · 定義是開關，也是工具

### 全章設計句

```text
核心 insight：
定義有兩個方向：要證「x 是偶數」，你必須造出一個整數 k；已知「x 是偶數」，你就拿到一個整數 k。
兩個方向的內容一字不差，差別只在誰提供。

學習者原本可能怎麼誤解：
1. 「是不是偶數」靠印象：0 不算、負數怪怪的。
2. a ∣ b 就是 a / b，或 b / a。
3. 「找不到 k」等於「我試了幾個都不行」。
4. 已知 x 是偶數時，挑一個值（x = 4）代表它；或把兩個已知拿到的整數都叫 k。

第一個具體問題：0 是偶數嗎？−6 呢？7 呢？先憑感覺下注。

一般機制如何表述：
「x 是 P」若定義成「存在 …… 使 ……」，那麼：
證明它＝造出那個東西（一個證人就夠）；推翻它＝說明「每一個都不行」（需要理由）；
已知它＝拿到那個東西，但它的值不是你選的，只能用定義保證的性質。

主例子的 accidental properties：
- 只用正數：0、−6、−7 進場，−7 的 k 是 −4 而不是 −3。
- 只用 a ≠ 0：3 ∣ 0、0 ∣ 3、0 ∣ 0 全部進場。
- 兩個奇數取同一個值（1 + 1）：例子生成時拒絕 a = b，並用 7×7 組合格子顯示「同名」只談到對角線。
- 已知「x 是偶數」時，學習者心中的 x 是某個特定值：先請他猜 x，立刻回應「也可能是 −10、0……」；之後的具體列一律包含他的 x 和另外兩個偶數，檢查式子時第一個試的是 x = 10（k = 5）。
- 有理數的分母只想到正數：檢查用的 (p, q) 含負的 q；q ≠ 0 的理由選項裡放「因為 q 是正數」當誘答。

哪個 non-degenerate state 讓角色真正分開：
3 + 5（k = 1、m = 2）：兩個拿到的整數不同，「同名」寫法立刻失效。
x = 10（k = 5）：常數答案「4」立刻失效。

主要視覺模型：
「倍數數線」：圓點是 a × k (+ c) 在 k 取整數時能到的值，目標值是琥珀色箭頭。
落在圓點上＝開關開；夾在兩個圓點之間＝開關關，並標出夾在哪兩個 k 之間。
「已知／目標板」（Ch6 正式狀態板的預覽）：拿到的東西用「↳ 拿到的」粗左邊框；造出的東西用「✎ 你造的」方角框。

視覺可能造成的假暗示：
數線只畫一小段，可能讓人以為「在畫面上找不到」就是「找不到」。
對策：7 的「找不到」不由畫面決定，而由「2k = 7 的唯一解 3.5 不是整數」這個理由決定；數線只是把理由畫出來。
具體列和例子表格可能被當成證明。對策：2.3 的三列明標為「線索」，緊接著標「理由」的那一行展開；2.4、2.5 的表格收在「看幾個例子（只是檢查，不是理由）」裡。

預測 → 回饋 → 壓縮：
2.1、2.2 先下注；2.3 先猜 x；2.4 先挑例子；每一幕最後壓成一句。

evidence 類型：
2.1、2.2 的「成立」是 WITNESS（一個 k）；「不成立」是 GENERAL ARGUMENT（唯一解不是整數，或 0 × k 恆為 0）。
2.3–2.5 的 □ 是 GENERAL ARGUMENT（代數恆等式）；系統以固定的檢查值驗算，錯誤回饋寫成「試 x = 10（這時 k = 5）：左邊…；右邊…」，畫面明說那些值只是例子。

省略了哪一筆 proof debt：
「a ∣ b 且 a ≠ 0 ⇔ b / a 是整數」只陳述不證；證明文字的寫法（Ch6–7）。

最後如何檢查能否遷移：
2.5 換成有理數：兩個證人、外加 q ≠ 0 的條件。學習者要自己說出新分母為什麼不是 0。
```

### 2.1 · 0 是偶數嗎？

- **衝突／預測：** 0、−6、7 是偶數嗎？三個按鈕：是／不是／說不準。全部下注才能繼續。
- **可操作模型：** 偶數定義出現後，在 `n = 2 × □` 填 k，數線同步標出目標與 2k 能到的值。按「找不到整數 k」時，若其實找得到就提示；若是 7，改問「不管整不整數，k 要是多少？」，學習者填 3.5 後得到理由：唯一解不是整數。
- **奇數：** 三題完成後解鎖奇數定義，試 −7（k = −4）。
- **壓縮圖卡：** 「是不是偶數，問定義：找得到整數 k 嗎？找得到，一個就夠；說找不到，要給理由。」
- **展開層：** 為什麼 k 一定要是整數；「說找不到要給理由」與 Ch1 的關係。

### 2.2 · 3 整除 0 嗎？

- **衝突／預測：** 3 ∣ 12、12 ∣ 3、3 ∣ 0、0 ∣ 3、0 ∣ 0，先下注成立／不成立。
- **可操作模型：** 同一台機器：`b = a × □`。a = 0 時數線上只剩一個點，標「0 × k 永遠停在 0」。12 ∣ 3 走「k 要是多少？」的同一條路；0 ∣ 3 直接給理由。
- **∣ 與 / 分類：** 3 ∣ 12、12 / 3、3 / 12、0 ∣ 0、0 / 0 分成「一句話／一個數／沒有定義」。0 ∣ 0 成立但 0 / 0 沒有定義，是用乘法定義整除的理由。
- **壓縮圖卡：** 「a ∣ b 是一句話：b 是不是 a 的整數倍。它用乘法定義，所以連 0 都講得清楚。」
- **展開層：** 要求 a ≠ 0 的教材 convention。

### 2.3 · 你拿到一個 k

- **衝突／預測：** 「已知 x 是偶數，x 可能是多少？」學習者填一個偶數，系統回應「也可能是 −10、0……題目沒說是哪一個」。
- **單欄工作紙（2026-11-09 改版）：** 第一版用左右兩欄的已知／目標板，窄螢幕時板子掉到文字下方，「按右邊」失效；「對手」與 □ 也沒有先介紹。改成由上而下一步一步：
  1. 秀出偶數定義，學習者替**自己猜的 x** 填 k（`4 = 2 × □`），系統補上「x = −10 時 k = −5」：x 換了，k 跟著換。
  2. 出現「↳ 拿到的：k 是整數、x = 2k」框，並用一句話說明框的意思（左邊加粗＝拿到的；藍色方框＝你造的）。
  3. 目標「x + 6 是偶數」：先說明 □ 是要你填整數的空格，再填三列具體值（學習者的 x、−10、0）的 □，接著問「□ 跟 k 有什麼關係？」，用 k 寫出 □。三列標為線索，`2 × (k + 3) = 2k + 6 = x + 6` 標為理由。
  4. 第二個目標「4 ∣ x²」：先用學習者的 x 算一列，再用 k 寫；錯一次後出現提示「x² = (2k) × (2k)」。
  原本的第三個目標 `x + 1 是奇數` 刪除，避免同一幕裝太多。
- **壓縮圖卡（本章核心）：** 「要證『是偶數』，你得造出一個 k；已知『是偶數』，你就拿到一個 k。」

### 2.4 · 兩個名字

- **衝突／預測：** 「兩個奇數相加是偶數」。先挑兩個不同的奇數當參考；a = b 會被拒絕並說明原因。
- **可操作模型：** 依序展開兩個已知。第二個問「也可以叫 k 嗎？」。選「可以」時，b 的框變成紅色虛線，7×7 組合格子只亮對角線，學習者自己的例子不在其中。改成 m 後全部亮起，再造出 `a + b = 2 × (k + m + 1)`。
- **壓縮圖卡：** 「每用一次定義，就拿到一個新名字。用同一個名字，等於偷偷假設它們相等。」

### 2.5 · 新定義，同一套動作（transfer）

- **造出：** 0.75 = p / q（任何一組都行，0.75 不是整數、q = 0 都有針對性回饋）；−2 = −2 / 1。
- **拿到：** 已知 r 是有理數 → 拿到 p、q、q ≠ 0。目標 r / 2 → `p / (2q)`；再回答「2q 為什麼不是 0」；目標 r + 1 → `(p + q) / q`。
- **收束表：** 三個定義 ×「要證它：你得造出／已知它：你就拿到」，兩欄內容相同。
- **壓縮圖卡（全章）：** 「定義有兩個方向：要證它，你得造出定義要的東西；已知它，你就拿到那些東西。」
- **五步預告卡（2026-11-10 加入）：** 章末用 x + 6 的例子列出定義型證明的五步：寫下已知和目標 → 展開已知 → 展開目標 → 接起來 → 檢查附加條件。學習者先選「哪一步真的需要想」，之後每步標上「照定義」或「要想」，只有第 4 步是「要想」，並提示「朝第 3 步給的形狀整理」。這張卡只是預告，正式的狀態板與步法卡仍在 Ch6–7。

### Ch2 畫面與實作約束

- 證人輸入以 `ch2/ch2-expr.ts` 解析：整數、小數、單字母變數、隱含乘法（`2k`、`3(k+1)`、`km`）、`^` 與 `²`；以有理數精確計算，不用浮點判斷整數。

## Ch3 詳細 storyboard · 「若…則」是一個承諾

### 全章設計句

```text
核心 insight：
「若 P 則 Q」只承諾一件事：P 成立時，Q 也成立。
四種情況裡只有「P 成立、Q 不成立」那一格算違約；P 不成立時承諾沒被觸發，不算違約。

學習者原本可能怎麼誤解：
1. 「或」是二選一：12 是偶數也大於 10，就不算「偶數或大於 10」。
2. 沒考 100 分卻吃到冰，等於爸爸說錯話；沒考 100 分也沒吃到冰，是「不知道」。
3. 檢查「若 P 則 Q」要去找 P、Q 都成立的例子（Wason：翻 A 和 4）。
4. 前提不可能時，句子是假的或沒意義。
5. 「若 P 則 Q」和「若 Q 則 P」說的是同一件事。

第一個具體問題：「n 是偶數，或 n > 10」：12 算不算？

一般機制如何表述：
P、Q 各有成立／不成立，共四格。每個連接詞就是在四格裡圈出它成立的格：
且＝一格、或＝三格、非 P＝下半排、若 P 則 Q＝除了違約格以外的三格、P ⇔ Q＝對角線兩格。

主例子的 accidental properties：
- 3.1 的數字若剛好每格一個以上或某格空著，會讓人以為格子數量有意義：用 4、7、12、15，每格恰好一個。
- 冰淇淋例子的「沒觸發」兩格在故事裡也許顯得「不公平」：只問「爸爸有沒有食言」，不問爸爸做得好不好。
- 3.5 若只用一個真的原句，學習者看不出逆命題會失敗：原句選「4 的倍數 ⇒ 偶數」，讓逆命題在 n = 6 失敗。

哪個 non-degenerate state 讓角色真正分開：
n = 12 讓「或」的包含性可見；n = 6 讓原句和逆命題一真一假；Wason 的 7 背面是 E，讓「沒翻 7」的後果可見。

主要視覺模型：
「四格圖」：上排 P 成立、下排 P 不成立；左欄 Q 成立、右欄 Q 不成立。每格標字：成立／不成立，或守約／違約／沒觸發／不可能。
違約格用朱色方框＋「違約」字樣；不可能用斜線紋＋「不可能」；你的選擇用琥珀外框。不只靠顏色。

視覺可能造成的假暗示：
四格裡放具體的數，可能讓人以為「放幾個數檢查」就證明了關於所有 n 的句子。
對策：3.2 的「為什麼違約格永遠空著」用第 2 章的理由（4k = 2 × 2k），不是用放進去的數；3.6 的數字明標「例子，不是證明」。
3.5 的四格完整列舉則是真的證明（原句與逆否句等價對任何 P、Q 都成立），兩者在畫面上用不同印章區分。

預測 → 回饋 → 壓縮：
3.1 先選數；3.2 先選哪幾種算食言；3.3 先選要翻的卡；3.4 先判斷會不會食言；3.5 先猜哪一句和原句同義；3.6 先點違約格。每幕最後壓成一句。

evidence 類型：
3.5「原句與逆否句等價」：FINITE EXHAUSTION，而且真的是證明，因為 P、Q 的真假組合只有四種。
3.5「逆命題不成立」：WITNESS（n = 6）。
3.2、3.6 的數字：EXAMPLE；真正的理由是第 2 章式的展開。

省略了哪一筆 proof debt：
量詞（「對每個 n」）只用中文，符號 ∀ 留給 Ch4；「若…則」裡藏著的「對每個 n」在 Ch4 才正式拆開。

最後如何檢查能否遷移：
3.3 從字母卡換成喝酒年齡（結構相同、表面不同）；3.5 從冰淇淋換成整除。
```

### 3.1 · 12 算不算？（且、或、非）

- **衝突／預測：** P：n 是偶數；Q：n > 10。數字卡 4、7、12、15。「n 是偶數，或 n > 10」：哪些數讓它成立？漏掉 12 時，說明數學的「或」包含兩個都成立。
- **可操作模型：** 四格圖出現，四個數落進各自的格。接著學習者直接在格子上圈「且」（一格）與「非 P」（下半排）。
- **壓縮：** 三張迷你四格圖並排：P ∧ Q（and）、P ∨ Q（or）、¬P（not）。
- **壓縮圖卡：** 「用且、或、非接起來的句子，就是在四格裡圈出它成立的格。『或』圈三格：兩個都成立也算。」
- **展開層：** 日常的二選一（exclusive or）是另一種圈法：只圈「恰好一個成立」的兩格。

### 3.2 · 什麼時候算食言？（若…則）

- **衝突／預測：** 爸爸說：「如果你這次考 100 分，我就請你吃冰淇淋。」四種情況，哪幾種算食言？可複選。
- **可操作模型：** 揭曉時每種情況就地說明，再放進四格圖：守約、違約、沒觸發、沒觸發。命名「若 P 則 Q」（if P then Q，P ⇒ Q）。
- **為什麼這樣約定：** 「若 n 是 4 的倍數，則 n 是偶數。」學習者把 8、6、3 點進格子；違約格（4 的倍數卻不是偶數）永遠空著，理由是第 2 章的 4k = 2 × (2k)。如果把「沒觸發」算成假，這句人人同意的話在 n = 6 就變成假的——所以數學約定：沒觸發算真。
- **壓縮圖卡：** 「『若 P 則 Q』只承諾一件事：P 成立時，Q 也成立。只有『P 成立、Q 不成立』那一格算違約。」

### 3.3 · 該翻哪幾張？（Wason 選卡）

- **衝突／預測：** 每張卡一面是字母、一面是數字。桌上 A、K、4、7。規則：「如果一面是母音，另一面就是偶數。」最少要翻哪幾張？
- **揭曉：** 每張卡的背面有兩種可能，各落在哪一格；只有可能落進違約格的卡要翻（A、7）。翻開：A 背面 8（守約）、7 背面 E（違約）。
- **遷移：** 「如果在喝酒，就必須滿 18 歲」：喝啤酒、喝可樂、25 歲、16 歲。再把兩組卡一一對應，結構相同。
- **壓縮圖卡：** 「檢查『若 P 則 Q』，只看可能落進違約格的：P 成立的，和 Q 不成立的。」
- **展開層：** Wason（1966）的原始實驗與確認偏誤；喝酒版本為何比較容易。

### 3.4 · 永遠不會被觸發的承諾（空洞為真）

- **衝突／預測：** 哥哥說：「如果你這次考 120 分，我就把手機送你。」（滿分 100）哥哥可能食言嗎？
- **可操作模型：** 四格圖上排整排標「不可能」，違約格在其中，所以永遠不會違約。數學版：「若 n 既是偶數又是奇數，則 n = 100」；把「則」後面換成 n < 0、1 = 2，句子仍然成立。
- **壓縮圖卡：** 「前提不可能成立，違約格就永遠空著：這種承諾自動成立，不管『則』後面接什麼。這叫空洞為真（vacuous truth）。」
- **展開層：** 為什麼沒有數又是偶數又是奇數（第 2 章的理由）。

### 3.5 · 反過來說，還是同一句嗎？（逆命題與逆否命題）

- **衝突／預測：** 原句「若 n 是 4 的倍數，則 n 是偶數」。A：若 n 是偶數，則 n 是 4 的倍數。B：若 n 不是偶數，則 n 不是 4 的倍數。哪一句和原句同義？
- **可操作模型：** 同一張四格圖，學習者替 A、B 各點出違約格。A 在另一格（裡面有 6），B 和原句同一格（空的）。
- **證據：** 四格全部看過，原句與逆否句的違約格相同，對任何 P、Q 都成立——完整列舉在這裡是證明。逆命題不成立則只靠 n = 6 一個反例。
- **壓縮圖卡：** 「換句話說時，看違約格有沒有搬家：逆否沒搬，是同一句話；逆命題搬了，是另一句話。」
- **展開層：** 否命題（inverse）和逆命題在同一格違約。

### 3.6 · 兩個承諾疊在一起（若且唯若）

- **衝突／預測：** P ⇔ Q 是兩個承諾。點出所有違約格（兩格），剩下對角線：P、Q 同真同假。
- **檢查兩句：** 「n 是 4 的倍數 ⇔ n 是偶數」：6 落在違約格，不成立。「n 是偶數 ⇔ n + 1 是奇數」：數字都落在對角線，但那只是例子；理由是兩個方向各證一次。
- **收束：** 五張迷你四格圖：且、或、非、若…則、若且唯若。
- **壓縮圖卡（全章）：** 「『若 P 則 Q』只怕一格：P 成立、Q 不成立。換句話說、檢查、證明，都看那一格。」

### Ch3 畫面與實作約束

- 共用四格圖 `ch3/grid4.component.ts`：上排 P 成立、左欄 Q 成立，全章位置固定；格子可點選時是按鈕，有可見 focus 與完整的 aria-label（例如「P 成立、Q 不成立」）。
- 版面為單欄（`.pf-scene.solo`），四格圖緊跟在引用它的文字後面；文字不寫「右邊」「左邊」，直接說「四格圖」。
- 每個新名詞與新視覺元件第一次出現時，用一句話說明（2.3 改版的教訓）。
- 符號 ∧、∨、¬、⇒、⇔ 一律在具體操作之後才出現，並附英文讀法。

### Ch3 完成驗收

學習者離開本章後應能：

1. 在四格圖上圈出且、或、非、若…則、若且唯若成立的格，並說出「或」包含兩個都成立。
2. 說出「若 P 則 Q」只在哪一種情況是假的，以及為什麼「沒觸發」算真。
3. 檢查一條「若…則」規則時，只去找 P 成立的和 Q 不成立的。
4. 判斷空洞為真的句子成立，並說出理由。
5. 分辨逆命題與逆否命題，知道哪一個和原句同義、為什麼。
6. 知道證明 P ⇔ Q 要證兩個方向。


## Ch4 詳細 storyboard · 量詞是一場對手遊戲

### 全章設計句

```text
核心 insight：
「對每個 x」由對手出招，「存在 y」由你出招；句子裡量詞的順序就是出招順序。
後出的人看得到前面的招，所以換了順序，就換了一場遊戲，真假也可能跟著變。

學習者原本可能怎麼誤解：
1. 「對每個 x 存在 y」和「存在 y 對每個 x」用的字一樣，意思也一樣。
2. 證明「對每個 x」就是多試幾個 x（第 1 章已處理，這裡從遊戲角度再看一次）。
3. 回應對手時只能出一個數；不知道 y 可以「看著 x 決定」，寫成依賴 x 的規則。
4. 一句話的真假只看文字，不看 x、y 從哪裡挑（domain）。
5. 平常的數學句子沒有量詞（「偶數加偶數是偶數」）。

第一個具體問題：
A「對每個整數 x，都存在整數 y，使 y > x」與 B「存在整數 y，使得對每個整數 x，都有 y > x」：都成立嗎？

一般機制如何表述：
把一句量詞句讀成一場輪流出招的遊戲：由左到右，每個「對每個」輪到對手、每個「存在」輪到你；
最後檢查條件。你有必勝策略，句子就成立；對手有必勝策略，句子就不成立。

主例子的 accidental properties：
- y > x 的規則幾乎都是「y = x + 常數」，可能讓人以為規則一定是「加一點」：4.5 改用 x + y = 0，規則是 y = −x。
- 只用 ∀∃／∃∀ 會讓人以為量詞永遠是兩個且一前一後：4.4 加入兩個「對每個」（∀∀）與藏在「若…則」裡的單一 ∀。
- 對手若只出正數，壞規則（2x、x²、x / 2）也會贏：對手的固定招式含 0、負數、奇數與大數。
- 4.5 對手規則 x = y 在 y = 0 時失敗（0 + 0 = 0），讓「看起來會贏的規則」被一招打破。

哪個 non-degenerate state 讓角色真正分開：
A 與 B 只差順序，一真一假；ℤ 與 ℕ 只差負數，同一句話一真一假；
4.5 你和對手的規則都依賴對方的招（y = −x、x = 1 − y），兩個角色的「看著對方決定」都可見。

主要視覺模型：
「出招順序條」：量詞依句子順序排成一列，對手的招是虛線框「對手出」、你的招是實線框「你出」，
與第 6 章起的證明狀態板身份標記一致（任意的＝虛線、你選的＝實線）。
「回合紀錄」：每一回合列出對手的招、你的招與檢查結果；文字「贏／輸」加 ✓／✗，不只靠顏色。

視覺可能造成的假暗示：
規則在對手的固定招式上全贏，可能被誤讀成證明。對策：數字回合只標「例子」；
規則全贏後，還要有一個對每個 x 都成立的理由（例如 y − x 永遠等於 1），才蓋「證明」印；
找不到這樣的理由時，畫面明說「這仍是例子」。

預測 → 回饋 → 壓縮：
4.1 先判斷 A、B 的真假；4.2 先出一個 y 再看對手怎麼回；4.3 換世界前先預測規則還能不能贏；
4.4 先替每個空格填「對每個／存在」；4.5 先出一招，再寫對手的規則。每幕壓成一句。

evidence 類型：
數字回合：EXAMPLE。你的規則＋「y − x 是正的常數」：GENERAL ARGUMENT（證明）。
對手的規則＋「x = y 時 y > x 永遠不成立」：GENERAL ARGUMENT（推翻 B）。
ℕ 裡的 x = 0：WITNESS（一個 x 就推翻「對每個 x」）。

省略了哪一筆 proof debt：
不談否定的機械規則（第 5 章）；4.5 讓學習者當對手，只預告「否定＝交換角色」。
「x² = 2 沒有有理數解」只陳述，證明留給第 8 章。規則的一般性只接受「差值是常數」這一種理由；其他寫法誠實標成例子。

最後如何檢查能否遷移：
4.3 固定句子、換 domain；4.5 換關係（x + y = 0）並交換角色。
```

### 4.1 · 比 x 大的數，永遠找得到嗎？（對手先出）

- **衝突／預測：** A、B 兩句並列，學習者各自下注成立／不成立／說不準。
- **為什麼要有對手：** 「對每個 x」代表最刁鑽的 x 也得過關，所以請一位專找碴的對手挑 x；「存在 y」只要找得到一個，所以 y 由你挑。
- **可操作模型：** 對手依序出 7、1000000；學習者每回合打一個數。接著對手說「我可以一直出下去」：改成寫規則 y = □（可用 x）。對手用固定招式 0、−8、7、1000000、−1000001 測試；整數檢查與 y > x 檢查逐列顯示。
- **證據：** 數字回合只是例子；規則全贏且 y − x 是正的常數，才蓋「證明」。
- **壓縮圖卡：** 「『對每個 x』由對手出招，『存在 y』由你出招。你後出，所以 y 可以看著 x 決定：寫成一條規則，就能一次回答所有的 x。」
- **展開層：** 對手為什麼只要贏一回合（回接第 1 章：一個反例就推翻「所有」）。

### 4.2 · 如果你得先出呢？（換了順序）

- **衝突：** B 的順序反過來：你得先出 y，對手看過 y 才挑 x。輸入框只接受數字；打 x 會說「這時 x 還沒出現」。
- **可操作模型：** 學習者出 y，對手回 x = y，檢查 y > y 失敗；可以多試幾次。接著問：「有沒有哪個 y 能贏？」
- **證據：** 對手的規則 x = y 對每個 y 都贏，理由是 y > y 永遠不成立：蓋「推翻」。
- **對照與命名：** A、B 的出招順序條並排；白話：A＝沒有最大的整數，B＝有一個整數比所有整數都大。符號 ∀（for all）、∃（there exists）在此出現，並在每個量詞下標「對手出／你出」。
- **壓縮圖卡：** 「量詞的順序就是出招順序。後出的人看得到前面的招。換了順序，就換了一場遊戲。」

### 4.3 · 在自然數裡還成立嗎？（換一個世界）

- **先玩一次：** C「對每個 x，都存在 y，使 y < x」，世界是 ℤ。學習者寫規則（y = x − 1），蓋「證明」。
- **衝突／預測：** 句子一字不改，世界換成 ℕ = {0, 1, 2, …}（scope label 持續顯示）。「你的規則還能贏嗎？」
- **回饋：** 對手第一招就出 0（ℕ 最小的數）。規則給出 −1，不在 ℕ 裡；學習者再自己打一個數試，也贏不了。ℤ 的規則與「證明」留在畫面上，ℕ 另起一張句子卡和出招順序條，兩個世界上下對照。
- **證據：** x = 0 一個招就推翻「對每個 x」（WITNESS）。
- **壓縮圖卡：** 「量詞一定要說清楚從哪裡挑。世界一換，對手能出的招就不同，同一句話的真假也可能跟著變。」

### 4.4 · 這句話藏了幾個「對每個」？

- **任務：** 三句平常的數學句子，各自改寫成完整版，學習者替每個空格選「對每個／存在」，再看出招順序條。
  1. 「偶數加偶數是偶數。」→ 對每個偶數 a、對每個偶數 b，a + b 是偶數（對手出兩招，回接第 2 章兩個名字）。
  2. 「若 n 是 4 的倍數，則 n 是偶數。」→ 對每個整數 n（回接第 3 章：放 8、6、3 進四格圖，就是對手出了三個 n）。
  3. 「每個整數都有相反數。」→ 對每個整數 x，存在整數 y，使 x + y = 0（為 4.5 鋪路）。
- **壓縮圖卡：** 「讀一句數學，先把藏起來的量詞找出來，再排出招順序：誰出、從哪裡挑、誰先。」
- **展開層：** 「x² = 2 有解」少了什麼？domain：在 ℝ 有解，在 ℚ 沒有（第 8 章證明）。

### 4.5 · 換你來找碴（遷移與角色交換）

- **你出招：** D「對每個整數 x，存在整數 y，使 x + y = 0」。寫規則 y = −x；x + y 永遠是 0，蓋「證明」。
- **換你當對手：** E「存在整數 y，使得對每個整數 x，都有 x + y = 0」。系統先出 y = 4，學習者打一個 x 讓 x + y ≠ 0；再寫對手規則 x = □（可用 y）。系統的固定招式含 y = 0、−1，讓 x = y、x = 1 這類規則被打破；x + y 是不為 0 的常數（例如 x = 1 − y）才蓋「推翻」。
- **全章壓縮圖卡：** 「讀量詞句就是排出招順序：『對每個』由對手出，『存在』由你出。後出的人可以看著前面的招決定；順序一換，遊戲就換了。」
- **展開層：** 生活版：「每把鎖都有一把鑰匙打得開」與「有一把鑰匙打得開每把鎖」。
- **下一章預告：** 這一幕你當了對手；否定一句話，就是讓你和對手交換位置。

### Ch4 畫面與實作約束

- 單欄（`.pf-scene.solo`），沿用第 3 章。
- 共用：`ch4/moves.component.ts`（出招順序條）與 `ch4/rule-game.component.ts`（輸入規則 → 對手固定招式測試 → 一般理由）。規則用第 2 章的 `parseExpr` 解析，精確有理數運算。
- 對手招式逐題手寫、決定性，可重播；不使用隨機。
- 「一般理由」只接受「關鍵量（y − x、x + y）在多個測試點都等於同一個常數，且常數符合條件」；其他全贏的規則誠實標成例子，請學習者換一條看得出理由的規則。
- 符號 ∀、∃ 在 4.2 具體玩過之後才出現，附英文讀法；畫面上的量詞一律寫出範圍（ℤ 或 ℕ）。

### Ch4 完成驗收

學習者離開本章後應能：

1. 把一句量詞句讀成出招順序：誰出、從哪裡挑、誰先。
2. 說出 A（∀∃）和 B（∃∀）為什麼一真一假。
3. 為「存在」寫一條依賴前面招式的規則，而不是只回一個數。
4. 知道換 domain 可能改變真假，並用一個對手的招推翻「對每個」。
5. 找出平常數學句子裡藏起來的量詞。
6. 站在對手的位置，為一句不成立的話寫出必勝規則。

## 章數與範圍決策

採 **26 章、約 100 節**。章數多是因為本課每一章的 insight 都很小、很基礎，而這些基礎正是後續所有課程的地基；合併會讓一個畫面同時承擔兩個新動作。

- Part 0（Ch1）建立「證據有強度」的動機。
- Part I（Ch2–5）把數學語言拆成可操作的結構：定義、條件句、量詞、否定。
- Part II（Ch6–12）建立狀態板與七種骨架形狀。
- Part III（Ch13–16）處理「骨架有了，中間沒想法」的瓶頸。
- Part IV（Ch17–20）把步法遷移到集合、函數、關係與基數。
- Part V（Ch21–24）把「批改者」的工作拆成學習者自己能做的檢查。
- Part VI（Ch25–26）以 ε–N 總考量詞遊戲，並以診斷收束。

**排序理由：**

- **語言先於步法**：多數「不會證」其實是「讀錯陳述要求什麼」。
- **步法先於找想法**：Pólya 式的啟發法，需要先有骨架才知道是在找哪一段的想法。
- **找想法先於新材料**：集合、函數的證明相對機械，放在後面當遷移測試，檢查步法是否真的能帶到新物件上。
- **自我驗收放在最後**：要先累積足夠多的證明，才有東西可以挑錯；但骨架卡複習從 Ch6 起每章都會出現，Ch23 只是把這個習慣正式化。

**刻意不納入主線：**

- 形式邏輯系統（natural deduction 的完整規則、soundness／completeness）：本課只取它的步法直覺。
- Lean／proof assistant 本身：狀態板借用它的「目標狀態」介面，但不教語法；外部的 Natural Number Game 列為延伸資源。
- 計數與組合（排列組合、二項式）：屬於另一門課，本課只在例題中使用最基本的計數。
- 公理化集合論（ZFC）、選擇公理：只在 Ch20 展開層點到。
- 競賽型解題技巧的完整清單：Part III 只收四個最可遷移的啟發法。

## 逐章交付與驗收方式

### 全課 accidental-property audit 摘要（各章實作時再逐項展開）

- **只用正數當例子**會讓學習者忽略 0 與負數——Ch2 用 0、−6、`0 ∣ 0` 開場。
- **兩個物件用同一個例子值**（例如兩個偶數都取 2）會讓變數身份混淆看不見——Ch2、Ch6、Ch7 都刻意用數值不同的 non-degenerate 例子。
- **順序無關的量詞句**（`∀∀`）會讓「順序＝出招順序」看不見——Ch4 主例必須讓順序改變真假。
- **只用質數測試整除命題**會讓 Euclid 引理看起來對所有整數成立——Ch13、Ch22 用 `4 ∣ 2·2`。
- **隨機對手或隨機模擬**會讓「贏很多次」看起來像證明——對手一律採決定性的最壞情況策略，模擬一律標 `SIMULATION`。
- **小世界的完整檢查**會被誤讀成一般定理的證明——UI 區分「此小世界內已證明」與「一般情況」。
- **文氏圖**會被當成證明——Ch17 用四個圓畫不出 16 區的例子明示它的極限。
